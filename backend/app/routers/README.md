# routers 目录说明

## 核心作用
定义所有后端 API 路由，负责参数校验、鉴权依赖注入、调用业务服务并返回响应。

## 包含模块
- `interview.py`：面试主流程、评估、成长曲线、成长建议、报告下载。
- `resume.py`：简历上传/分析/优化/下载。
- `job.py`：岗位管理与岗位查询。
- `questions.py`：题库管理与题目生成。
- `knowledge.py`：知识库上传/查询/管理。
- `rag.py`：RAG 检索入口。
- `users.py`：用户注册登录与信息接口。

## 调用关系
路由层仅编排流程与参数处理，核心业务逻辑下沉至 `services` 与 `crud`。
